BAGIAN 2: LANGKAH-LANGKAH PRAKTIK & AKTIVITAS MAHASISWA (Durasi: 00:45 - 02:00)
--------------------------------------------------------------------------------
[Visual di Layar: Tampilkan Visual Studio Code, arahkan mouse ke struktur folder dan file weather_api.ts serta index.html]

Dialog yang Diucapkan:
"Baik, sekarang kita masuk ke langkah-langkah praktik yang telah saya lakukan.

Pertama, kita mempersiapkan lingkungan kerja menggunakan Node.js dan TypeScript serta antarmuka web responsif berbasis HTML5, CSS3, dan JavaScript.

Kedua, mari kita perhatikan URL API yang diberikan pada soal tugas, yaitu:
https://api.open-meteo.com/v1/forecast?latitude=-6.2&longitude=106.8&hourly=temperature_2m

API ini mengembalikan respon berformat JSON yang merepresentasikan prakiraan cuaca wilayah DKI Jakarta pada koordinat lintang minus 6,2 dan bujur 106,8.

Ketiga, di file weather_api.ts, saya mendefinisikan tipe data menggunakan TypeScript interface: ada HourlyData untuk menampung array time dan temperature_2m, serta HourlyUnits untuk satuan temperaturnya.

Proses pengambilan data dilakukan secara asinkron menggunakan fungsi bawaan fetch() dengan async/await yang dibungkus blok try-catch untuk penanganan galat (error handling).

Setelah data JSON berhasil diambil, program mengekstrak data waktu dan suhu, kemudian memformatnya ke dalam format tabel yang rapi. Di sini, program menampilkan 10 data pertama sesuai instruksi soal, lengkap dengan statistik suhu minimum, maksimum, dan rata-rata.

Selain skrip CLI TypeScript, saya juga merancang antarmuka mobile-responsive di file index.html dengan desain kartu modern mirip Ionic Framework, agar data cuaca dapat dibaca dengan sangat mudah di layar smartphone."

BAGIAN 3: HASIL DAN ANALISA PRAKTIK (Durasi: 02:00 - 03:30)
--------------------------------------------------------------------------------
[Visual di Layar: 
 1. Jalankan di terminal: node --experimental-strip-types --no-warnings weather_api.ts
 2. Perlihatkan jendela browser index.html, demokan badge suhu dan tombol toggle]

Dialog yang Diucapkan:
"Sekarang kita masuk ke pengujian hasil dan analisa praktikum.

(Sambil menjalankan script di terminal):
Dapat kita lihat di terminal, saat saya menjalankan perintah 'node --experimental-strip-types --no-warnings weather_api.ts', aplikasi berhasil terhubung dan memuat data prakiraan cuaca Jakarta.

Data cuaca berhasil diparse dan ditampilkan secara rapi. Terlihat 10 baris data pertama, dimulai dari waktu 00:00 dengan suhu 26,8 derajat Celsius hingga jam 09:00 dengan suhu 29,2 derajat Celsius, serta suhu tertinggi mencapai 33,8 derajat Celsius pada jam 05:00. Program juga menghitung suhu rata-rata 10 jam pertama sebesar 30,5 derajat Celsius.

(Sambil beralih ke jendela browser index.html):
Selanjutnya, ini adalah tampilan antarmuka pengguna pada browser. Desainnya mengadopsi standar aplikasi mobile perangkat bergerak dengan kartu informasi status koneksi, koordinat Jakarta (-6.2, 106.8), zona waktu GMT+0, serta tabel responsif.

Tiap baris menampilkan nomor urut, waktu pengukuran yang telah diformat ramah pengguna, dan nilai temperatur lengkap dengan indikator badge warna visual. Terdapat pula tombol interaktif untuk beralih antara menampilkan 10 data pertama sesuai instruksi soal atau menampilkan seluruh 168 jam data prakiraan sepekan.

Analisa dari praktikum ini membuktikan bahwa arsitektur REST API dengan format JSON sangat efisien untuk aplikasi mobile, karena ukuran payload-nya ringan, tidak membebani kuota data seluler, dan pengolahan data array paralel 'time' serta 'temperature_2m' dapat dipetakan secara presisi berpasangan per indeks waktu."
